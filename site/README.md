# Portfolio Website

This directory contains the offline-ready portfolio website.

## Files

- `index.html`: main website.
- `tailwind.js`: local Tailwind CSS script for offline use.
- `image/`: project image assets used by the gallery.

## Publish

1. Push the `site/` folder to your GitHub repository.
2. Enable GitHub Pages from the repository settings.
3. Set the source to the branch containing `site/` and the folder to `/site` or copy `index.html` to the repository root.

## Notes

- The site is self-contained and does not require an external Tailwind CDN.
- External links such as Behance and Dribbble are preserved for navigation.
